淡江橋譜 介面 v2 視覺稿

方向一句話：淡江牌桌是綠桌布加淡江藍的 App，橋譜要是米紙、墨、朱砂的一本書。下面五個畫面都是用 v2 的 token 直接排出來的，不是截圖；切換系統深色模式可以看到「夜讀」版。規格在 docs/DESIGN-V2.md，實作拆在 PRD 的 E9。

現況（M0）

Swagger 式卡片堆、整本一頁、頁首七個圖示鈕、淡江藍與牌桌同色、沒有入口頁。

v2

首頁是入口；一特約一頁、三欄閱讀；頁首只有 Logo、制度集、搜尋、帳號；襯線標題、細線表格、印章式「待確認」。

與牌桌的區分

牌桌：綠桌布、淡江藍、宮燈。橋譜：米紙、朱砂、靛、書。只共用 Logo 家族與四色花色。
