## 背景

同一本橋譜要服務零基礎新生和國手。現在的網站把 2010 年講義、Jacoby 2NT 的七階詢問叫和 Lebensohl 平鋪在一起；新生不知道從哪開始，也看不懂「GF」「splinter」「NMF」。E1 已給每個特約與段落 `level`，E4 把它變成閱讀體驗：入門版、學習路徑、名詞解釋、導讀。

## 目標

- **程度標籤**顯示在卡片、目錄、搜尋結果；三級：入門／進階／高階。
- **入門版／完整版**切換：入門版隱藏進階與高階段落（留一行「還有 n 個進階段落」）。
- **學習路徑**：「從零開始」一條（之後可多條）：課次 → 讀哪幾段 → 做哪幾題（E6）→ 自我檢核；登入後記進度。
- **名詞解釋**：glossary 資料；內文自動偵測名詞加底線、浮動解釋；獨立名詞頁。
- **導讀**：每個特約可有一段「為什麼用它、什麼時候用、常見錯誤」（`intro` 區塊），入門版也看得到。

## 非目標

- 不做影片、不做課程報名。
- 不做自動判定使用者程度；程度是使用者自己選的閱讀模式。

## 需求

### 功能

- 程度對照（與牌桌機器人等級）：入門 ≈ 初學者、進階 ≈ 大專、高階 ≈ 公開組／橋士組。對照表寫進 `CONTENT_GUIDE.md`。
- 閱讀模式存在偏好（`PreferencesContext`）；新生預設入門版（未登入第一次進站問一次「你是新生嗎？」）。
- `LearningPath`：

  ```ts
  interface LearningPath { id: string; name: string; lessons: Lesson[] }
  interface Lesson { id: string; title: string; goal: string; readings: { slug: string; sectionId?: string }[]; quizIds?: string[]; checklist: string[] }
  ```

  內建一條「從零開始」（由幹部編：第 1 課 牌的基本／點力 → 第 2 課 開叫 → … → 第 8 課 常用特約），線上可編。
- 進度：`progress:<userId>:<pathId>` 記完成的課；路徑頁顯示百分比。
- Glossary：`Term { term: string; aliases: string[]; definition: string; see?: slug }`；`RichText` 偵測（只在完整詞、每段落只標第一次）；浮動解釋用 Popover（鍵盤可開）。

### 非功能

- 入門版的段落隱藏是 CSS 加 aria，不改資料；列印依目前模式。
- 名詞偵測的效能：預先編譯成一個正規表達式，每段落一次。

## 設計方向

- 入門版切換放在閱讀設定（E9 的「閱讀設定」面板），與主題、字級同一處。
- 學習路徑頁是首頁（E9）給新生的主要入口：「第一次來？從第一課開始」。
- 名詞底線用細點線＋小圖示，和一般連結分得開（`DESIGN-V2.md`）。
