## 背景

M0 的介面是 Swagger UI 的翻版：一整頁卡片堆、每張卡再疊多層手風琴、頁首七個圖示鈕、導覽藍與淡江牌桌同一組 token。它是工具，不像書；而且和牌桌長得太像。設計規格在 [`../DESIGN-V2.md`](../DESIGN-V2.md)，中國風視覺稿在 [`../design/mockup-v2.html`](../design/mockup-v2.html)，六種風格×四種版面與個人設定的展示頁在 [`../design/pitch.html`](../design/pitch.html)。E9 是把規格做進程式碼。

## 目標

- 預設風格「一般」保留現行配色與圓角；另外五種風格（中國風、圓潤、夜讀、四色、極簡）做成 token 組讓使用者自選；Logo 不變。
- 新版面：**首頁**是入口（社團新聞、我的制度集、第一次來、分類、最新討論、最近更新），**特約頁**依個人設定的版面顯示（整本一頁為預設，另有三欄閱讀、專注單欄、卡片總覽）。
- 頁首只留：Logo、制度集切換、搜尋、帳號；展開／收合、主題、字級、入門版、列印收進一個「閱讀設定」面板。
- 手機：單欄閱讀、底部工具列（目錄、搜尋、閱讀設定）；列印：書頁樣式。
- 編輯器、管理頁、登入頁換皮，不改流程。
- 無障礙與效能不退步：對比 AA、鍵盤、`prefers-reduced-motion`；特約頁 LCP ≤ 1.5 秒。

## 非目標

- 不改內容模型、不改 API（E1、E10 做）。
- 不做動畫秀；動效只在翻頁與面板開合。

## 需求

### 功能

- `styles/tokens.ts` 全面改為 v2 token（色、字體、字級階、間距、圓角、陰影），舊 token 名稱保留別名一個版本後移除。
- 路由：`/` 首頁；`/c/:slug` 特約頁（`/c/:slug/:sectionId` 捲到段落）；`/book` 全書目錄（取代「整本一頁」，可選「印整本」）；其餘路由不變。
- 首頁區塊：制度集卡（目前制度集、採用數、最後更新、「讀制度」「制度卡」）、「第一次來？」（E4 路徑）、分類入口、最近更新、叢書（E5 之後）、練習（E6 之後）；未登入看到的是社團預設。
- 特約頁：左欄全書目錄（目前分類展開）、中欄正文（章節編號、程度、來源、覆寫標記、叫牌表、備忘）、右欄本頁段落導覽＋「上一個／下一個特約」；段落仍可收合（預設展開第一層）。
- 閱讀設定面板：主題（跟隨／淺／深）、字級、入門版／完整版、本頁全部展開／收合、列印本頁。
- 手機：頂部細列（Logo、制度集、搜尋）＋底部工具列；目錄與閱讀設定為抽屜。
- 列印：書頁樣式（頁眉特約名、頁碼）；深色模式列印仍黑白。

### 非功能

- 視覺回歸：Playwright 對首頁、特約頁、制度卡、編輯器各一張截圖（桌機＋手機、淺＋深）進 CI。
- 不混用兩套樣式：換皮在一條分支完成後一次合併（可拆多個 PR 到同一條功能分支）。

## 設計方向

見 `DESIGN-V2.md`。要點：

- 色：米紙底、墨字、朱砂主色（連結、重點、覆寫標記）、靛為結構色（章節編號、第一層段落左框）、宮燈金只做細線；深色是「夜讀」暖黑。
- 字：標題 Noto Serif TC、內文 Noto Sans TC、叫品 tabular。
- 版面：正文 68 字寬；三欄 18rem／1fr／14rem；手機單欄。
- 元件：段落像書的節（§2.1），不是卡片；叫品表為細線表格、叫品欄固定寬；待確認用「印章」式標記；覆寫用左側朱砂線＋小字來源。
